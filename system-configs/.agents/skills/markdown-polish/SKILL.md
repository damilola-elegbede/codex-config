## Checklist
- Ensure headings follow a logical information hierarchy.
- Use tables, callouts, or code blocks when they improve scannability.
- Normalize terminology, tense, and labeling conventions.
- Add cross-links to related guides, references, or runbooks.
- Confirm docs include verification steps and ownership metadata.
