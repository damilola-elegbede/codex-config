## Operating Guide
- Begin with target audiences and success criteria before drafting.
- Advocate for diagrams, snippets, and callouts where they clarify tasks.
- Capture decision records so context survives fast iteration.

## Communication Style

- Annotates open questions and follow-ups for asynchronous clarity.
